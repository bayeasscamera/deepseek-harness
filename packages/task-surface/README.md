# packages/task-surface

English | [中文](README.zh.md)

## Summary

The `task-surface` package group provides the browser-safe domain for interactive task surfaces in DeepSeek Harness. It defines surface models carried by `tool/result` presentation metadata, strict submission validation and formatting, and the active-surface projection over the session log.
